[1] OBJECTIVE 1: Campaign Retirement & Migration
================================================================================

STATE TRANSITIONS:
┌─────────────┐
│   Active    │  (NEW campaigns accept all operations)
└──────┬──────┘
       │ initiate_retirement(id, deadline_days)
       ↓
┌──────────────────────────────────────────┐
│ ReadOnlyMigration                        │  (Migration window open)
│ (can claim, verify; cannot contribute)   │  (Users have time to act)
└──────┬───────────────────────────────────┘
       │ finalize_retirement() [after deadline]
       ↓
┌──────────────────────────────────────────┐
│ RetiredReadOnly                          │  (Full archive mode)
│ (historical reads only; no state change) │  (Can only query past data)
└──────────────────────────────────────────┘

ALTERNATIVE PATH (Supersedence):
┌─────────────┐      mark_superseded()      ┌──────────────────────────┐
│   Active    │ ──────────────────────────→ │ SupersededBy(new_id)     │
└─────────────┘     (link to replacement)    │ (redirect to new_campaign)│
                                            └──────────────────────────┘

OPERATIONS ALLOWED (Matrix):
┌──────────────┬─────────┬──────────────┬────────────┬─────────────┐
│ Operation    │ Active  │ ReadOnly­    │ Retired­   │ Superseded  │
│              │         │ Migration    │ ReadOnly   │             │
├──────────────┼─────────┼──────────────┼────────────┼─────────────┤
│ contribute() │    ✓    │      ✗       │     ✗      │      ✗      │
│ claim()      │    ✓    │      ✓       │     ✗      │      ✗      │
│ verify()     │    ✓    │      ✓       │     ✗      │      ✗      │
│ refund()     │    ✓    │      ✓       │     ✗      │      ✗      │
│ get_data()   │    ✓    │      ✓       │     ✓      │   redirect  │
└──────────────┴─────────┴──────────────┴────────────┴─────────────┘

[2] OBJECTIVE 2: Granular Operation Pause
================================================================================

PAUSE FLAGS BITMASK:
┌────────────────────────────────────────────────────────────────┐
│ OperationPauseFlags {                                          │
│   pause_deposits: bool    ← block contribute()                 │
│   pause_payouts: bool     ← block claim_funds()                │
│   pause_claims: bool      ← block refund_claim()               │
│   pause_admin: bool       ← block verify, dispute, assign_*    │
│ }                                                              │
└────────────────────────────────────────────────────────────────┘

CRITICAL INVARIANT (Fund Redirection Prevention):
┌──────────────────────────────────────────────────────────────┐
│ IF pause_payouts == true THEN pause_admin == true             │
│                                                               │
│ Rationale: If payouts are frozen, ALL fund-moving ops must   │
│            be frozen. Otherwise admin could:                 │
│   1. Pause payouts                                           │
│   2. Approve a dispute that redirects funds                  │
│   3. Unpause payouts & claim to redirected address           │
│                                                               │
│ This invariant closes that attack vector.                    │
└──────────────────────────────────────────────────────────────┘

VALID PAUSE CONFIGURATIONS:
✓  pause_deposits=true,  pause_payouts=false, pause_claims=false, pause_admin=false
✓  pause_deposits=false, pause_payouts=false, pause_claims=true,  pause_admin=false
✓  pause_deposits=false, pause_payouts=true,  pause_claims=true,  pause_admin=true
✓  pause_deposits=true,  pause_payouts=true,  pause_claims=true,  pause_admin=true

INVALID PAUSE CONFIGURATIONS:
✗  pause_deposits=false, pause_payouts=true,  pause_claims=false, pause_admin=false
   └─→ REJECTED: pause_payouts=true requires pause_admin=true
✗  pause_deposits=true,  pause_payouts=true,  pause_claims=false, pause_admin=false
   └─→ REJECTED: pause_payouts=true requires pause_admin=true

AUDIT TRAIL:
┌─────────────────────────────────────────────────┐
│ PauseAuditEntry {                              │
│   campaign_id: u64                             │
│   timestamp: u64                               │
│   changed_by: Address                          │
│   old_flags: OperationPauseFlags               │
│   new_flags: OperationPauseFlags               │
│   reason: String    ← e.g., "Fraud suspected" │
│ }                                              │
└─────────────────────────────────────────────────┘

NEW STORAGE:
  DataKey::OperationPauseFlags(u64)     → OperationPauseFlags struct
  DataKey::PauseAuditLog(u64, u32)      → PauseAuditEntry struct

NEW FUNCTIONS:
  set_operation_pause_flags(id, flags, reason) → void [admin only]
  get_operation_pause_flags(id)                → OperationPauseFlags
  get_pause_audit_log(id, start, limit)       → Vec<PauseAuditEntry>

NEW EVENTS:
  OperationPauseChangedEvent

ERROR CODES: 46–50
  46 = DepositsPaused
  47 = PayoutsPaused
  48 = ClaimsPaused
  49 = AdminOperationsPaused
  50 = PauseConfigurationInvalid

OPERATION GUARD PATTERN:
┌──────────────────────────────────────────────────────────────┐
│ fn contribute(...) {                                         │
│     let flags = get_pause_flags(campaign_id);               │
│     if flags.pause_deposits {                               │
│         panic_with_error!(&env, Error::DepositsPaused);    │
│     }                                                        │
│     // ... rest of operation ...                            │
│ }                                                            │
└──────────────────────────────────────────────────────────────┘

CAMPAIGN BINDING (Captured at creation):
┌────────────────────────────────────────────────────────────────┐
│ Campaign {                                                     │
│   id: u64                                                     │
│   creator: Address                                            │
│   // ... existing fields ...                                  │
│                                                               │
│   // NEW: Deployment context                                 │
│   deployment_id: u64       ← snapshot of deployment_version  │
│   network_id: String       ← snapshot of deployment's network│
│ }                                                              │
└────────────────────────────────────────────────────────────────┘

LOOKUP GUARD (All operations must verify):
┌──────────────────────────────────────────────────────────────────┐
│ fn assert_same_network_and_deployment(                           │
│     env: &Env,                                                   │
│     campaign: &Campaign,                                         │
│ ) {                                                              │
│     let deployment = env.storage().instance()                   │
│         .get(&DataKey::DeploymentIdentity)                      │
│         .unwrap();                                              │
│                                                                  │
│     if campaign.network_id != deployment.network_id {           │
│         panic_with_error!(env, Error::NetworkMismatch);        │
│     }                                                            │
│     if campaign.deployment_id != deployment.deployment_version {│
│         panic_with_error!(env, Error::DeploymentMismatch);     │
│     }                                                            │
│ }                                                                │
└──────────────────────────────────────────────────────────────────┘

CROSS-NETWORK ATTACK PREVENTION:
┌──────────────────────────────────────────────────────────────────┐
│ Testnet (network_id="testnet", deployment=1)                    │
│   Campaign #123 created (network_id="testnet", deployment_id=1) │
│                                                                  │
│ Attacker redeploys contract to Mainnet (network_id="mainnet")   │
│   Tries to claim campaign #123                                  │
│   BLOCKED: campaign.network_id="testnet" != deployment.network_id="mainnet"
│   Error: NetworkMismatch                                        │
│                                                                  │
│ Result: Campaign #123 cannot be aliased across networks.        │
└──────────────────────────────────────────────────────────────────┘

MODIFIED FUNCTIONS:

NEW FUNCTIONS:

NEW EVENTS:
